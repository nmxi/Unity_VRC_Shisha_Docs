mikinel Shisha SystemはVRChat内でシーシャを楽しむためのUdon製ギミックです。

このアセットには

<ul class="shisha-mode-list">
  <li class="shisha-mode-basic">Basicモード</li>
  <li class="shisha-mode-advanced">Advancedモード</li>
</ul>

の2種類のモードがあります。

### Basicモード

Useするだけで吸えるモードです。

本体はポン置きでOK、フレーバをシーシャ本体に当てることで吐く煙の色の変更が可能です。

- パイプ持つ
- Use吸う
- 色を変える

### Advancedモード

シーシャのセットアップを行ってから吸えるようになるモードです。

フレーバをセット、炭焼き、加熱、蒸らしを行う必要があります。

- フレーバをセット
- 炭を加熱
- 炭を乗せる
- 炭をセット
- 待つ
- 吸う
- 炭を変える

BasicモードとAdvancedモードで導入方法が違うので注意して下さい。

## mikinel Shisha System上での用語定義

![シーシャの各パーツの名称](/img/notion/intro/parts.png)

| 用語 | 説明 |
| --- | --- |
| シーシャ本体 | トップとヒートシステムで作られた煙を水を介してホースに流す部分。 |
| トップ | フレーバが入っているところ。 |
| ヒートシステム | 炭を入れるところ。 |
| フタ | ヒートシステムに乗せるフタ。本物のシーシャではこのフタをずらしたりして炭の温度調節を行うが、このギミックではその機能は無い。 |
| ホース | シーシャ本体に接続され、パイプまで煙を運ぶパーツ。 |
| パイプ | 手に持って煙を吸うパーツ。口のつけるところはマウスピースとも呼ばれたり。 |
| フレーバ | たばこの葉に様々なものを加えてペースト状にしたもの。このギミックでは フレーバの違い = 吐く煙の色の違い となる。 |

## 注意点

- 1つのワールド内のシーシャのボトルの推奨最大設置数は一旦4つとします。
それ以上の数を設置しても動作しますが、パフォーマンスに影響が出る可能性があります。

## Tips

- 明るいワールドよりも暗いワールドの方が煙が映えます
- 水を光らせたいときはマテリアルのEmissionをいじってみて下さい
- Advancedモードの炭の加熱時間と燃焼時間は変更できます。
